RQ1 · 控制

高动态接触

接触阶段可变阻抗是否在不牺牲 Onset 精度的情况下，降低峰值力与力度波动？

RQ2 · 学习

样本效率与泛化

辨识模型 + 安全约束残差是否减少真机数据，并改善未见琴键的性能？

对照：无模型、无残差、无随机化。

RQ3 · 协同

臂手时空规划

指法与手掌轨迹联合优化能否提高跨音区演奏 F1 并减少碰撞？

对照：固定手位、独立规划。

创新性是待验证的研究假设，不是既成结论。HandelBot 已使用真实残差 RL，因此必须在接触物理、稳定性和样本效率上提供新的证据。

04

核心技术路线与数学模型

MuJoCo / RoboPianist 作为可复现仿真起点；先模型基线、再安全约束下的学习增强。

T1 · 触键动力学

辨识琴键接触模型

mₖ ẍₖ + bₖ ẋₖ + kₖ xₖ + Fₙₗ = Ffinger

mₖ(kg) 等效质量，bₖ(N·s/m) 阻尼，kₖ(N/m) 刚度，xₖ(m) 行程，Fₙₗ(N) 非线性作用力。数码钢琴与机械钢琴分开建模。

T2 · 接触阻抗

接近 → 接触 → 压键 → 释放

Mᵈ ë + Dᵈ(t) ė + Kᵈ(t)e = Fext

e(m) 指尖位置误差；Mᵈ(kg)、Dᵈ(N·s/m)、Kᵈ(N/m) 为期望等效动力学参数。模式切换需连续与限幅。

T3 · 残差学习

模型控制器为安全底座

u = u_model + sat(Δu_π)

u 为统一单位的执行指令（如关节力矩）；学习残差只修正时序、局部轨迹或受限力矩，不绕过底层安全。

T4 · 臂手协同

离散指法 + 连续轨迹

min Jnote + Jtime + Jcollision + Jeffort

先分配左右手与手指，再优化手掌与指尖轨迹。复杂跨音区场景增加局部联合优化和碰撞约束。

05

评价指标与实验协议

L1 物理控制 → L2 动作执行 → L3 音乐与泛化；每项都要求可追溯的原始数据和测量条件。

层级指标定义 / 计算测量依据
L1指尖位置 RMSE√[Σ‖pᵢ−pᵢ*‖²/N]；mm外部视觉或位移计
L1接触力 RMSE√[Σ(Fᵢ−Fᵢ*)²/N]；N独立力传感器；力控就绪后
L1接触峰值与冲量max F(t)；∫F(t)dt，N、N·s高采样率测力台
L1刚度实现误差|Kmeas−Kcmd|/Kcmd力—位移实验
L2重复击键极限满足成功率/时序约束的最大频率；HzMIDI + 同步时间戳
L2Onset MAE / P95|tactual−ttarget| 的均值/95分位；ms配对 MIDI Note On
L2和弦同步误差同一和弦最晚−最早 Note On；msMIDI
L3音符 Precision / Recall / F1TP/(TP+FP), TP/(TP+FN), 2PR/(P+R)预定义音高与时间匹配容差
L3Velocity MAE匹配音符 |vactual−vtarget| 均值；0–127MIDI；不是指尖接触力
L3跨琴键泛化差距训练工况与留出测试工况的 F1 差严格分割曲目/琴键/钢琴

论文、展示与长期研究路线

论文贡献必须以可证伪实验支撑；Demo 体现系统能力，但不能代替消融和真实测量。

Contact-Aware Control

琴键辨识 + 接触阶段阻抗 + 安全残差；比较高频、力度与跨琴键泛化。

Paper B · 后续

Whole Arm-Hand Coordination

联合指法、手掌轨迹与多指时序，面向复杂跨音区任务。

Engineering

Prima + Linka Demo

高质量双手演奏视频、可复现评测报告和可迁移的控制/规划模块。

长期扩展：4–8个月：学习融合与复杂曲目；8–12个月：机械钢琴触键动力学、跨乐器适应、真实声学评价。Genesis 物理仿真引擎作为扩展实验平台，不阻塞 MuJoCo 基线。
